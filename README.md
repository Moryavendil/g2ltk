# g2ltk

Useful python functions for data analysis with python.

* Video reading & writing
* Advanced Fourier transform routines
* Useful plotting macros

This is still being built.

## Installation

`pip install g2ltk` installs what `g2ltk.arrtools` and `g2ltk.fourier` need. The other subpackages need optional dependencies:

| Subpackage | Install with |
|---|---|
| `g2ltk.plotting` | `pip install "g2ltk[plot]"` |
| `g2ltk.videoreading` | `pip install "g2ltk[video]"` |
| `g2ltk.rivulets` | `pip install "g2ltk[full]"` (it uses both plotting and video reading) |

* Package on [PyPI](https://pypi.org/project/g2ltk/)
* Source code on  [GitHub](https://github.com/Moryavendil/g2ltk)
